# Credit Card Classification and Car Price Regression

This project explores machine learning techniques to tackle two tasks:
1. **Binary Classification** on a credit card dataset for **credit score prediction**
2. **Regression Analysis** on a car price dataset for **car price prediction**

## Project Overview
This project aims to evaluate and compare different machine learning models for classification and regression tasks, specifically focusing on credit score prediction and car price estimation. The models used include K-Nearest Neighbors, Decision Tree, Naïve Bayes, and Multinomial Logistic Regression. 

### Key Achievements:
- Achieved **98% accuracy** using **Multinomial Logistic Regression** for credit card classification.
- Reached an **R² score of 95%** using **Decision Tree Regression** for car price prediction.

## Model Selection & Tuning
Some models were fine-tuned and optimized using `GridSearchCV` to enhance performance for each specific task. The final models showcase the efficacy of algorithm selection.
